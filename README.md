# TRAFFIX – Smart Traffic Management System

## About
TRAFFIX is a web-based traffic management application designed to simplify traffic-related activities for citizens and traffic officers.

## Features
- Citizen and Officer Login
- Vehicle Management
- Traffic Challan Management
- Payment Status Handling
- Traffic Reports
- Traffic Signal and Density Management
- Emergency Traffic Management

## Technologies Used
- **Frontend:** HTML, CSS
- **Backend:** Java Servlets
- **Database:** MySQL
- **Connectivity:** JDBC
- **Server:** Apache Tomcat 10.1

## Database
The application uses MySQL tables such as `users`, `vehicles`, `challans`, and `traffic_reports`.

## How to Run
1. Set up MySQL and execute `sql/traffix.sql`.
2. Configure the database connection in `DBConnection.java`.
3. Deploy the application on Apache Tomcat 10.1.
4. Open `http://localhost:8080/TRAFFIX/` in your browser.
